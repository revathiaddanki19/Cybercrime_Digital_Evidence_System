
# Cybercrime Digital Evidence Management System

## About the Project

The Cybercrime Digital Evidence Management System is a web-based application designed to manage digital evidence related to cybercrime investigations.

It provides a centralized platform for investigators and administrators to manage cases, upload digital evidence, verify file integrity, and maintain a chain of custody.

## Technologies Used

### Frontend
- HTML
- CSS
- JavaScript
- Bootstrap

### Backend
- Python
- Flask

### Database
- MongoDB

## Key Features

- Secure user authentication
- Role-based access control
- Cybercrime case management
- Digital evidence upload and management
- SHA-256 evidence hash generation
- Evidence integrity verification
- Chain of custody tracking
- Investigation activity logs
- Search and filtering
- PDF report generation
- Admin dashboard
